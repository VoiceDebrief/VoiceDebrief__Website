## The System In One Picture

```
                        USER DEVICE (browser / iOS / Android app)
   .opus/.ogg/.m4a  ->  detect format BY CONTENT
                        decode (browsers decode Opus and AAC natively)
                        ONE PASS:  STT -> analysis -> debrief -> [infographic]
                        UI, mode selector, key + session in local storage
                              |                          |
                    routed / restricted mode      browser-local mode
                              v                          v
                        OpenRouter                nothing leaves
                        (inference + per-key      the device
                         billing & metering)      (possibly free)
                              |
                        shared account balance  (operator-funded float)
                              ^
                        key-provisioning Lambda  [DEFERRED — beta uses a
                        (the ONLY server code)    hardcoded capped key]

   HOSTING: GitHub Pages (S3 + CloudFront where needed).  NO BACKEND.
```

## Delivery Shape

```
   THIS REPO
     +-- dev branch  --CI-->  test -> auto-tag -> build all targets -> dev estate
     +-- main branch --CI-->  test -> auto-tag -> build all targets -> production
                                      web + iOS + Android   (Chrome extension later)
```

- Default branch is `dev` (changed 28 Jul). CI mirrors the sibling repos: tests gate an
  auto-tag step (`owasp-sbot/OSBot-GitHub-Actions git__increment-tag`), which bumps the
  root `version` file and pushes the tag; deploy jobs consume the bumped version.
- The mobile signing/deployment path (Apple developer key, Android key) has been walked
  before for SGraph and is reused, not reinvented.

## The Decisions And Their Consequences

| Decision | Consequence to hold |
|----------|--------------------|
| No backend | Static hosting; client holds data + key; near-zero cost base (what makes 25%-of-net viable at small volume) |
| OpenRouter = inference + billing | No billing code; margin = key credit limit; BUT operator pre-funds a single shared balance (float) |
| Privacy modes | Mode selector == billing tier; default is least private and must say so; browser-local is the only honestly "private" tier |
| One Lambda, deferred | Beta = hardcoded key: hard cap, short life, revocable, treated as public. Lambda lands when strangers arrive |
| Accounts optional | Google login or local-storage custody; cleared cache = lost credits (deliberate trade) |
| Format by content | Opus/Ogg is the norm (48kHz mono); AAC/M4A from iPhone app-to-app forwards; never trust the extension |

## Open Architecture Questions (from the arch brief, to be answered as reviews)

1. Client-side conversion vs sending each format directly to the model.
2. File length ceiling and its UI.
3. Model per mode; does the user pick the model or only the privacy tier.
4. Which on-device model powers browser-local mode, and on what hardware class.
5. Trigger for the Lambda (and its auth).
6. Abuse model for the public beta key.
7. Social login, local storage, or both; credit recovery.
8. Infographic: reuse the existing generator directly — one call or two.
