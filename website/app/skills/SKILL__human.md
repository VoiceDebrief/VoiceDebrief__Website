# VoiceDebrief — for humans

1. Get the recording as a file. A chat voice message (laptop → download, Android →
   share/export) arrives as `.opus`/`.ogg`; an iPhone forward or a Voice Memo arrives as
   `.m4a`. A meeting recording or a dictaphone file works the same way — the format is read
   from the file's content, not its name.
2. Drop it in, or press "see it work — no key needed" to watch a scripted example first.
   Nothing is asked of you to get this far.
3. Choose whether you want it translated into your language and whether you want an
   infographic. The page quotes the most this pass can cost before it runs.
4. Press Transcribe. If you have not saved an OpenRouter key yet, it is asked for here —
   once — and the pass carries on by itself. The key stays in this browser and goes only to
   OpenRouter. If you have not got one: https://whatsapp-voice-transcription.sgraph.ai/openrouter-key/
5. Transcript arrives first, then the translation if it was needed, then the debrief. Copy
   or download any of them.
6. Costs show in £ (converted from OpenRouter's USD metering). Nothing is stored on any
   server of ours — there is no server. Your audio IS sent to OpenRouter and on to a model
   provider we neither choose nor know, so do not use this for anything you would not hand
   to a third party.
