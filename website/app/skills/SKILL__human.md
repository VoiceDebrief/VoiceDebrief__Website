# WhatsApp Voice Note Transcribe — for humans

1. Get your voice note as a file: laptop WhatsApp → download (.opus); Android → share/export
   (.opus/.ogg); iPhone app-to-app forward (.m4a). All three work.
2. Paste your OpenRouter key (openrouter.ai/keys) once — it stays in this browser only.
3. Drop the file in. Transcript arrives first, then the summary. Copy or download either.
4. Costs show in £ (converted from OpenRouter's USD metering). Nothing is stored on any
   server of ours — there is no server.
