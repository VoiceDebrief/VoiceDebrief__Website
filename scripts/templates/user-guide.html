Using the tool, step by step

Every screenshot below was taken by a test that was, at that moment, proving the product works. When the app changes, the picture changes with it on the next build — this guide cannot quietly go out of date.

These images come from the QA-to-docs journeys (tests/qa-to-docs/), captured on CI against a scripted model so that every run produces the same pictures. No real voice note and no real API key is involved in making them — see the testing page for how the journeys work. When a picture moves, the change is recorded in the baseline change log against the commit that caused it.
