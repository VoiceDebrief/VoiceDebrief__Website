# LLM-friendly + SEO: llms.txt, sitemap, canonicals, JSON-LD, QA noindex

## Outcome 7 Aug 2026 — SHIPPED
- **/llms.txt** (the llms.txt convention): the agent-facing index — product
  summary, the `window.__tool` skills docs (SKILL__api/browser/human), the
  action manifest, the declared workflow file, and every machine-readable
  surface the site already emits (status/issues/docs/versions/updates/videos
  JSON + RSS). This site was already unusually machine-readable; now it says so
  in the standard place.
- **/sitemap.xml** generated by `build_content.py` (lastmod derived from
  content dates, never the clock); `robots.txt` names it.
- **Canonical tags** on every page and template, all pointing at the
  production domain.
- **JSON-LD**: SoftwareApplication on the landing page (free-beta offer,
  BYOK described); Blog on the Updates page.
- **The QA estate is noindexed at deploy** (qa-deploy injects
  `<meta name="robots" content="noindex">` into every page) — the preview can
  no longer compete with production in search. Production is untouched.
- **Live-QA** now checks /llms.txt, /sitemap.xml, /robots.txt, the API skill
  doc and the workflow declaration are reachable on every deploy.

Not done (conscious): per-post BlogPosting JSON-LD and VideoObject markup
(needs thumbnails/durations in content frontmatter — Journalist follow-up);
an OG share image (needs a designed asset).
