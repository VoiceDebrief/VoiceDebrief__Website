---
title: Every release now has a page — and you can see which one you're running
date: 2026-08-05
version: v0.1.19
---

There is now a [Versions page](/versions/): every release we have ever cut, newest first, with its date, a plain-English headline, what it changed and a link to the exact code diff. Updates tell the story; Versions is the complete list.

- The version number sits in the footer of every page and links to that timeline — so when something looks wrong, you can say exactly which build you were on.
- On this QA site the number carries a `-qa` suffix (for example `v0.1.19-qa.1a2b3c4`): it names the release being tested here *before* it reaches the live site.
