- Fixed: a finished run could be invisible (issue 046) — "do another voice note" and the remove-file ✕ reset the page without stopping the pass, which then completed into hidden sections; both reset paths now cancel the run in flight, and a pass that finishes with its results hidden puts them back on screen
- A user guide at /user-guide/ (issue 038), generated from the QA journeys: three sections, eight pictures, every one of them a screenshot taken by a test that was proving the product works in that same run — plus CI that commits new baselines so the guide has pictures and the screenshot gate can arm itself
- Browser unit tests (issue 049): a QUnit runner shipped with the site at /tests/browser/ — 11 tests across 5 modules, against real files, real stored settings and real page components; run headless on every deploy and reported as a layer on the engineering hub
- One menu, one source (issue 048): the site header is now a single `wa-site-nav` component on all 12 surfaces, replacing five drifted variants — the app page finally links the rest of the site
- LLM-friendly and findable (issue 047): /llms.txt indexes the site's agent-facing surfaces, /sitemap.xml is generated from the content dates, canonical tags point at production on every page, JSON-LD on the landing and Updates pages, and the QA estate is noindexed at deploy so the preview cannot compete with production in search
- Live-QA made honest about the network: link checks retry with backoff and a link that never answers is a loud warning, while a real 404 stays fatal; site-absolute stamped assets now resolve from the root rather than from /app/
