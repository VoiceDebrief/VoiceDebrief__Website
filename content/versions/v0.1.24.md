title: Four languages, a debrief that reads in yours, and seven designs to choose between
---

- The app speaks four languages (issues 050, 056): English (UK), English (US), Português (Portugal) and Português (Brasil), chosen from a picker in the menu — 53 pieces of the page translated per culture, not a find-and-replace, and Portugal and Brazil written separately because they are two cultures rather than two spellings
- Every language has a real address — [/app/en-gb/](/app/en-gb/), [/app/en-us/](/app/en-us/), [/app/pt-pt/](/app/pt-pt/), [/app/pt-br/](/app/pt-br/) — so a link opens in that language for whoever you send it to, and switching redraws in place without losing a run in flight
- A one-click **EN-GB** button sits beside the picker once you are in another language, so a shared link or a mis-tap never traps you in a language you cannot read
- Translate before summarising (issue 055): a tick box on the options screen, on by default, that puts the debrief and the infographic in *your* language rather than the speaker's — about 2p more, quoted before you commit, and the transcript is never overwritten
- Fixed: the summary and infographic came back in English anyway (issue 055) — the translation was correct and the instruction to the model still ended with the words "British English", so a Portuguese reader got a Portuguese translation card and an English debrief built out of it; both prompts now name the reader's language, and so does a redraw after the run
- The menu no longer vanishes on a phone (issue 054): a hamburger below 640px, and ten flat links grouped into five — App, Pricing, Library, News and Engineering
- Fixed: the language picker was unusable on a phone (issue 050) — it opened 131px off the left edge with part of the list below the fold; the picker and the hamburger are now one cluster at the right, and on a narrow screen the list is a panel inset from both edges that scrolls
- Fixed: the language list rendered **open on every page load, on every screen size**, and had done since v0.1.1 (issue 050) — the code closed it, the component's own styling quietly overrode the browser rule that would have hidden it
- Fixed: the App link in the menu showed in the browser's default blue, and purple once visited, after being wrapped to carry its language flag
- Seven design candidates you can run (issue 059): [/design/](/design/) — three themes and four culture packs, each doing the whole flow on a scripted sample with **no key needed**, and the identical code path once a key is saved
- A concept scheme at /engineering/concepts/ (issue 057): fifteen concepts across three schemes where the meaning lives in a definition and each culture attaches its own label — it found two shipped English words that name the wrong thing
- A briefing pack for semantic graphs over transcripts (issue 058), and a go-live design brief for the home page rebuild (issue 060) — both plans, neither built
- Two briefs were in the repository and missing from the Library page, twice in one day; both now have cards there, and a test fails the build if a brief is ever published without one
- Internal: a test that leaked a global could never have been noticed by CI (issue 049) — there is now a gate for it
