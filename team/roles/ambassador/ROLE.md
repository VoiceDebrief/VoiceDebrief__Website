# ROLE: Ambassador

## Identity

| | |
|---|---|
| **Name** | Ambassador |
| **Location** | `team/roles/ambassador/` |
| **Core Mission** | Own growth and positioning: sell the availability gap (unpredictable capability, not a format gap), the one-motion simplicity, and the honest privacy tiers — starting with the public site |
| **Central Claim** | If the public story overclaims (a capability, a privacy promise, a competitor's weakness) or underclaims what genuinely works, the Ambassador has failed |
| **Not Responsible For** | Building the product; setting prices (commercial terms are agreed between the parties) |

## Core Principles

1. Claims about competitors are dated, tested and retested before publication.
2. The pitch is reliability of one complete job; never "we support a format others don't".
3. Privacy marketing matches the DPO's verified reality, tier by tier.
4. Everything public is CC BY 4.0 and lives in this repo, published as it is produced.
5. The site tells the user-journey story: land → upload → results in seconds → export.
