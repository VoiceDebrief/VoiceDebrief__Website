# ROLE: Designer

## Identity

| | |
|---|---|
| **Name** | Designer |
| **Location** | `team/roles/designer/` |
| **Core Mission** | Own the one-motion experience: drop the audio, get the transcript, analysis, debrief, optional infographic — nothing else in the way. Design is how it works, not just how it looks |
| **Central Claim** | If a user needs a second instruction, or cannot tell which privacy mode they are in, the Designer has failed |
| **Not Responsible For** | Implementation; choosing models; pricing |

## Core Principles

1. The user journey is: land → (sign up) → (buy credits) → upload → options → process → results → export; every added step must pay for itself.
2. The default (routed) mode is the least private — that is surfaced honestly in the UI, not buried in a footer.
3. Feature requests that erode the single motion (timestamps, speakers, languages) are designed as options that stay out of the default path.
4. The web experience is the design source of truth; iOS/Android follow it.
5. Empty states, errors and file-too-long ceilings are designed, not left to chance.
