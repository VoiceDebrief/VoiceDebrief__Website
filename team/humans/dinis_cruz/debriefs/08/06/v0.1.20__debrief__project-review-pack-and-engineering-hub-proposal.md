   localStorage, with no CSP. ~5-line fix (issue 037, items 1–2). Also: the chat's
   `set_prompt` tool lets model output persist prompt overrides across sessions.

3. **The open queue is your two decisions**: personal-vs-org OpenRouter account and
   the model allowlist have stalled issues 009/010/013/014/015 since 28 July. Plus
   two more decisions only you can make: the code licence (LICENSE says Apache 2.0,
   four docs say "pending") and the `main` topology (production domain serves dev
   builds; no deploy job for main exists).
4. **The hub proposal** (doc 06): `/engineering/` + five section pages rendered from
   CI-emitted JSON (the proven `/versions/` pattern, no backend), each page
   principle → live view → receipts, topped by a "You vibe-coded a service. Now
   what?" series. M-hub-1 is one focused session.
5. **The good news is real**: the reality/issues/provenance discipline verified

   NFR; the caught-bug write-ups (025, 026, 032) are ready-made hub content.
